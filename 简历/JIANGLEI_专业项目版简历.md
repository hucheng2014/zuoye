## 核心项目

### 1. 强化学习量化交易系统（FreqAI RL）｜2025.10 — 2026.08　**【量化交易 · 数据工程 · 实盘/纸交易】**

独立负责策略代码、数据链路、评估与运行结果。Python / Docker / PostgreSQL / Freqtrade FreqAI RL。

- **工作内容：** 编写策略 `PureRL_FullAuto` 与 RL 环境 `MyRLEnv_FullAuto`；容器拉起交易进程与 PostgreSQL；纸交易与实盘配置、数据库隔离；用 SQL 查成交、订单、开仓状态做复盘。
- **技术选型：** FreqAI 强化学习为主路径；K 线 feather 落地；Walk-forward 按周切窗，对比 from-scratch 与 continual learning，多种子重复。
- **关键决策：** 回测关闭 live-only 状态增强，避免评估与实盘逻辑错配；上线前做 lookahead / recursive，降低未来函数；对无效 logits、时间戳漂移、限流、库损坏做日志巡检。
- **落地成果：** 「训练/回测 → 偏差检查 → 指标 CSV/JSON → 纸交易观察 → 实盘监控」闭环；监控拉持仓与接口；审计记录每笔 raw / sanitized / final action。
- **优化思路：** 聚合 Sharpe、Sortino、回撤与期望；备份含库导出、源码与配置，支持按快照回滚。

### 2. A 股策略回测（GitHub 开源仓 backtesting.py）｜2026.03　**【策略代码 · 行情数据工程】**

在开源回测框架上**亲自改策略、接行情、跑回测**（提交记录：添加回测用例、修改策略）。

- **工作内容：** 实现双均线交叉策略（金叉开仓、死叉平仓）；编写 A 股日线拉取、字段映射与数值化；输出收益、回撤、胜率等统计。
- **技术选型：** 事件驱动回测引擎；行情接口取前复权日线；佣金按 A 股万三、新信号覆盖旧订单。
- **关键决策：** 不用内置外盘样例数据，改为真实 A 股行情，使回测贴近国内交易成本。
- **落地成果：** 可复现的策略脚本 + 回测统计；完成从样例数据到 A 股数据管道的切换。
- **优化思路：** 策略与取数拆分到独立目录，便于换标的、换周期继续实验。

### 3. 多智能体交易回放（GitHub 开源仓 AI-Trader）｜2025.10 — 2026.03　**【量化研究复现】**

基于公开交易研究框架完成本地复现（非自研框架，重点在数据与回放流程）。

- **工作内容：** 日线行情获取与合并、回放服务、多智能体同期仿真、绩效统计。
- **技术选型：** 历史回放 + 防未来信息过滤；成交与持仓 JSONL 留存。
- **关键决策：** 定位为研究方法复现，讲清仿真回放与交易所订单链路的差异。
- **落地成果：** 打通数据准备 → 服务启动 → 回放运行 → 绩效统计。
- **优化思路：** 将回放中的记账与风控字段迁到自有 RL 审计日志。
