# AI Agent 自动化工作规范 — Duomotai 浏览器自动化

> **在开始做题前，请仔细阅读并严格遵守以下规则。这些是不可违反的硬性要求。**

---

## 项目简介

本项目通过浏览器自动化在平台上完成各类做题任务（申请、答题、提交等）。CDP 端口 `127.0.0.1:9239`，noVNC `http://127.0.0.1:6085/vnc.html`。

---

## 一、每道题必须独立判断，禁止硬编码

- 每道题必须独立读取和分析，不可批量套用。
- 不同类型的题目可能有不同的要求和格式。

---

## 二、必须使用现有脚本

**现有脚本（禁止从零重写）：**
- `click_apply.py` / `click_apply2.py` — 点击申请按钮
- `submit_answer.py` — 提交答案

**浏览器连接：**
- CDP proxy: `http://127.0.0.1:9239/json/version`
- noVNC: `http://127.0.0.1:6085/vnc.html`

---

## 三、严格按规则操作

- 提交前必须确认答案内容正确。
- 页面加载异常时等待而非刷新。

---

## 四、遇到错误必须及时汇报

- 页面加载失败 → **立即报告**。
- 登录/验证码/权限问题 → **立即通知用户**去 noVNC。
- 同一错误重试 **≤2 次**，仍失败则停止。
- **严禁**静默失败或假装成功。

---

## 五、提交前必须复检

- [ ] 答案内容已正确填写
- [ ] 页面无报错
- [ ] 提交后确认成功

---

## 工作流程检查清单

```
[ ] 1. 我已了解现有脚本的用途
[ ] 2. 我优先使用 click_apply.py / submit_answer.py
[ ] 3. 我的方案是每题独立处理
[ ] 4. 我知道遇到错误必须立即报告
[ ] 5. 我知道提交前必须复检
```
