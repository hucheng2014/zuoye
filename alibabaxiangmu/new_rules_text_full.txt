人声内部又分 3 层：
1.1 通用录音环境与质量（说话/唱歌的录音情况）
1.2 说话/演唱人档案（每个人的固定特征）
1.3 说话/歌词内容（逐句：时间戳 + 内容 + 情感） 记忆口诀：先讲整体环境 → 再建人物档案 → 再逐句写内容 → 最后补音效和背景音乐。
格式固定：[HH:MM:SS.mmm-HH:MM:SS.mmm] 必须精确到毫秒，时间戳精确度，小数点后一位，如 [00:09.000-00:11.000] 说话/歌词的每一句、每一条音效都要带时间戳 （如果caption把多句话合成一句话，需要按视频实际情况把这这一整句话切开）
大部分字段必填（见第 5 部分速查） 带【】的字段是可选，只有当本段相比"人物档案 / 整体环境"出现明显变化时才写： 【本段说话人动态属性】——如这句突然提高音量、语速变急 【本段声学环境/质量】——如这句环境声学明显变了 【本段视觉信息补充】——如本段画面有额外可补充的视觉信息 原则：没有明显变化就不要写，避免冗余
两者大框架一样，差异在 1.2 人物档案：
说话人档案：视觉标识、年龄与性别、口音/方言、基本音色特征、基本响度与节奏 演唱者档案：视觉标识、年龄与性别、基本音色特征、基本响度，外加三个演唱专属字段 → 演唱节奏、演唱风格、歌唱技巧与表现力 判断：这个人是在"说话"还是"唱歌"，决定用哪套档案字段
本部分只标"录音环境中的音效和背景声"，不描述背景音乐。拆成两类：
2.4.1 环境背景声：一句话描述。若背景声被 BGM 掩盖，写"背景声被 BGM 覆盖"。
2.4.2 音效：逐条列，每条 = 时间戳 + 音效内容。例： [00:00.000-00:04.000] 脚步声 [00:04.000-00:06.000] 高跟鞋脚步声
有 BGM 时，从 8 个维度描述： 音量 / 乐器 / 节奏与速度 / 录音质量与制作手法 / 旋律与和声 / 风格流派 / 氛围情绪 / 作用

说话人2：
视觉标识：身穿红色碎花连衣裙的女性。
年龄与性别：青年、女性。 口音/方言：标准普通话。
基本音色特征：清亮，略带尖锐感。
基本响度与节奏：正常音量，语速平稳。

背景音乐（视频本来没有，就写无，如果原文里边有描述，且符合这8个维度的，直接复制检查，如果原文描述，没有按照这8个维度的，把视频下载下来发给豆包，让豆包根据这8个维度，给出结果）
如果全程都是同一个背景音乐，就不要时间戳，如果背景音乐有变化，那就分段，带时间戳，时间戳格式参考说话/演唱和音效的格式
音量：柔和背景，贯穿始终，音量稳定，提供持续紧张氛围但不干扰对话。
乐器：以合成器为主，含低沉有节奏的合成器低音（类似心跳）及悬疑铺底音色。
节奏与速度：中速，节奏稳定且具重复性，制造压迫感。
录音质量与制作手法：录音室制作，音质清晰，偏现代影视配乐风格。
旋律与和声：几乎无明显旋律线，和声简单但充满不协和感，维持紧张状态。
风格/流派：电子音乐，悬疑风格影视配乐（Cinematic Underscore）。
氛围/情绪：紧张、悬疑、对峙感，带压迫感。
作用：烘托氛围，奠定紧张基调，以心跳般节奏推动情节。

❌ 常见错误：
直接照抄 caption1，尤其音效部分没按目标格式拆开 → 不合格。
时间戳精度不够（没到毫秒）或格式不对。
音效没有逐条带时间戳，混在一句话里写。
把背景音乐内容塞进"环境音与音效"，或反之。
唱歌场景用了说话人档案字段，漏掉演唱专属三字段。
没明显变化却硬填【】可选字段，造成冗余。
背景声被 BGM 盖住时没写"背景声被 BGM 覆盖"，而是凭空编。
①大合唱的“人声说话/演唱人档案:”如何标注，人数比较多，很难区分谁唱的什么声部
回答:可以将·合唱·认为是一个人，在视觉、音色等特征描述时按合唱来描述，举个例子:一群xoox的学生。音色:多人合唱，xxoxxxx
②镜头出现两个人，一个说话一个人未说话，人物档案需要建立未说话人的档案吗?
回答:不需要
③视频中出现短暂的英文，其余大部分都是中文，语言种类选“中文·可以吗
回答:按主要语种写
