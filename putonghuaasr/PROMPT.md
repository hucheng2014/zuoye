# AI Agent 自动化工作规范 — 普通话 ASR 标注

> **在开始做题前，请仔细阅读并严格遵守以下规则。这些是不可违反的硬性要求。**

---

## 项目简介

本项目在 **Sonic JD 标注页面**完成普通话 ASR（语音识别）标注任务：下载音频、跑本地双模型 ASR、按结果标注、填写并提交。**本地双 ASR 验证是硬性门槛，任何情况下不可跳过。**

---

## 一、每段音频必须独立验证，禁止跳过 ASR

### 绝对禁止项

1. **禁止使用页面"自动标注"按钮** —— 不可靠，高概率错题。
2. **禁止使用页面 ASR/paraformer/在线模型** —— 只能用本地 Qwen3-ASR 与 FireRedASR-AED。
3. **禁止跳过本地 ASR** —— 任何情况都必须先跑本地双模型。
4. **禁止仅凭备注硬判 SC** —— 只有备注与本地双 ASR 均指向同一文本，且音频确有清晰人声时才允许。
5. **禁止用提示词导致复读幻觉** —— 短音频必须结合无备注诱导的本地双 ASR 结果复核。

## 三、严格按规则操作

**标注分类（仅 3 种）：**

| 标签 | 含义 | 文本 |
|------|------|------|
| SC | 清晰可转写 | 填写文本（必须带合理中文标点） |
| SA | 方言/口音人声，普通话听不懂且无法确认文本 | 留空 |
| BS | 背景噪音/背景人声 | 留空 |

**关键规则：**
- SC 文本**必须有合理中文标点**（如 `好嘞，好嘞。`），禁止去掉标点。
- SA/BS 必须留空，不允许有文本。
- 音频 URL 必须从当前 Vue 状态获取，**不可缓存历史 URL**（签名有效期 ~1 小时）。
- 每段音频都必须保留并标注，**禁止删除任何人工分段**。
- 无分段/无效音频：在顶部选择"无效音频"后提交，**禁止**用行级 JSON 处理。
- 提交前必须在对话中展示：文件名、分段时间、双 ASR 结果、备注、最终标签和文本。

---

## 四、遇到错误必须及时汇报

- 双 ASR 下载或执行失败 → **立即报告**，不要绕过。
- 回填校验失败 → **立即停止**，禁止在已知失败后继续提交。
- 音频 URL 403 → 从 Vue 状态重新获取，连续 2 次失败则报告。
- **严禁**静默失败或假装成功。
- 禁止 shell 链式盲提（`cmd1 && cmd2 && submit`）。

---

## 五、提交前必须复检

**硬性提交门禁（全部通过才能提交）：**
- [ ] 本地双 ASR 已成功完成
- [ ] 最终方案行数 = 当前人工分段数
- [ ] 每行标签与最终方案完全一致
- [ ] 每行文本与最终方案完全一致
- [ ] 非 SC 行文本为空
- [ ] SC 文本有合理标点
- [ ] 当前分段仍存在于页面（未被自动删掉）
- [ ] 安全脚本返回 `ok: true`

**使用 `container_safe_fill_submit.py --expect-filename "当前文件名" --submit` 提交。**
