  核心问题

  你说的没错 — 获得题目、填写题目、检查题目、提交弹窗处理 这些步骤全部是由 extract_task.js、fill_task.js、check_tabs.js、full_submit.js 等脚本通过 CDP 直接操作浏览器完成的，不走 LLM。

  但问题在于：claw-code 不是这样工作的。claw 是一个自主 agent，它不会自动按 SOP 跑脚本。它的工作方式是：

  1. 你给它一个指令（"做这道 PROOFREAD 题"）
  2. 它自己决定用什么工具（Bash 执行脚本、Read 读文件、Write 写文件等）

    def _detect_intent(messages):
        """检测当前请求需要深度分析还是机械执行。
        Returns: "analysis" | "execution"
        """
        if len(messages) <= 1:
            return "analysis"  # 对话刚开始，需要思考

        # 找最后的用户消息和助手消息
        last_user = None
        last_assistant = None
        for msg in reversed(messages):
            if msg.get("role") == "user" and last_user is None:
                last_user = msg
            elif msg.get("role") == "assistant" and last_assistant is None:
                last_assistant = msg
            if last_user and last_assistant:
                break

        if not last_user:
            return "analysis"

        # 分析最后用户消息
        content = last_user.get("content", "")
        has_human_text = False
        has_tool_result = False
        tool_result_size = 0

        if isinstance(content, list):
            for block in content:
                if block.get("type") == "tool_result":
                    has_tool_result = True
                    rc = block.get("content", "")
                    if isinstance(rc, list):
                        tool_result_size += sum(len(b.get("text","")) for b in rc if b.get("type") == "text")
                    elif isinstance(rc, str):
                        tool_result_size += len(rc)
                elif block.get("type") == "text" and len(block.get("text","").strip()) > 10:
                    has_human_text = True
        elif isinstance(content, str) and len(content.strip()) > 10:
            has_human_text = True

        # 有人类指令文本 → analysis
        if has_human_text:
            return "analysis"

        # 无 tool_result → 不确定 → analysis（安全）
        if not has_tool_result:
            return "analysis"

        # 检查助手最后用了什么工具
        if last_assistant:
            acontent = last_assistant.get("content", "")
            if isinstance(acontent, list):
                for block in acontent:
                    if block.get("type") == "tool_use":
                        name = block.get("name", "")
                        inp = block.get("input", {})

                        # Write = 刚写完分析 → 下一步机械
                        if name == "Write":
                            return "execution"

                        # Bash 运行脚本 + 小输出 → 机械
                        if name == "Bash":
                            cmd = str(inp.get("command", ""))
                            script_cmds = ["node ", "npm ", "python3 ", "python ",
                                           "nohup ", "kill ", "ls", "pwd", "mkdir ",
                                           "cp ", "mv ", "tail ", "ps aux"]
                            if any(cmd.strip().startswith(p) for p in script_cmds):
                                if tool_result_size < 2000:
                                    return "execution"

                        # Read = 读文件准备分析 → analysis
                        if name == "Read":
                            return "analysis"

        # 按 tool_result 大小判断
        if tool_result_size < 500:
            return "execution"
        if tool_result_size > 2000:
            return "analysis"

        return "analysis"  # 默认安全

  六、Mission 系统（多 Agent 协作）

  CLI 中有完整的 Mission 系统，用于多 Agent 协作：

  文件路径： /opt/Alma/resources/cli/alma，第 5340-5460 行

  alma mission create "description" [--goals "g1" "g2" ...]  # 创建任务
  alma mission list [--all]                                    # 列出任务
  alma mission status <missionId>                              # 查看状态
  alma mission assign <missionId> --agent <taskId> [--role "..."]  # 分配 Agent
  alma mission progress <missionId> --goal <num> --status <status>  # 更新进度
  alma mission activate <missionId>                            # 激活任务
  alma mission complete <missionId> [--summary "..."]          # 完成任务

  Mission 数据结构包含 agents 数组，每个 agent 有：
  - taskId：agent 的任务 ID
  - role：在任务中的角色（默认 general）

  还有 comms 通信系统（第 5480-5560 行）：
  alma comms send <missionId> "message"      # 向任务频道发消息
  alma comms dm <agentTaskId> "message"       # 直接消息给特定 agent
  alma comms read <missionId> [--limit N]     # 读取频道消息
  alma comms inbox [agentId]                  # 查看收件箱
  alma comms broadcast "message"              # 广播给所有活跃任务

  环境变量 ALMA_AGENT_ID 用于标识当前 agent（默认为 alma）。
