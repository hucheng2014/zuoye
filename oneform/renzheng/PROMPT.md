# AI Agent 自动化工作规范 — renzheng 认证做题总入口

> **在开始做题前，请仔细阅读并严格遵守以下规则。这些是不可违反的硬性要求。**

---

## 项目简介

本目录是 **三个独立做题项目的总入口**，各项目有独立的脚本、流程和评分标准。进入哪个项目做题，就**严格遵循那个项目目录下的 CLAUDE.md 和 PROMPT.md**。

| 目录 | 任务 | 单题时长 |
|------|------|----------|
| `PROOFREAD/` | 中文校对 Eval（zh-CN/TW/HK，A/B/C 三响应判分+pairwise） | ~15 分钟（≥720s） |
| `TA Intelligent Polls/` | 投票生成评估（8 维度） | ~5 分钟（260~320s） |
| `VCGtexttoimage/` | 图片背景质量评估（A/B 两图侧对比） | 10 分钟（600s） |

**三者节奏和脚本布局完全不同，禁止把一个项目的命令套到另一个上。**

---

## 公共铁律（所有项目通用）

1. **禁止跳题**：绝不用 Skip Current Task，绝不跳过任何题/子题/选项。
2. **用当前页面的题做题**：禁止用旧答案填当前题，每题必须重新提取、独立分析。
3. **每题独立判断**：严禁纯硬规则/自动化打分；多维度互相独立，不互相污染。
4. **工具打开期间必须始终有保活脚本在跑**：否则累计 Inactive。
5. **同一时刻只能有一个 CDP 脚本连接**：多进程连同一端点会串行卡死。
6. **后台脚本一律 `nohup ... &` 并重定向日志**。

---

## 一、每道题必须独立判断，禁止硬编码

- 每道题必须独立读取、独立分析、独立决策。
- 各维度之间不得互相影响（如 Groundedness 问题不应影响 Following Instructions 判断）。
- **不同项目的评分体系完全不同**，不可混用。

---

## 二、必须使用各项目现有脚本

- 进入项目目录后，先读该项目的 `CLAUDE.md` 和 `PROMPT.md`。
- **使用该项目自己的脚本**，禁止跨项目混用脚本。
- 不确定用哪个脚本时，查看项目目录下的文档。

---

## 三、严格按规则操作

- 不确定判分时 → 查知识库：
  ```bash
  node pipeline/scripts/query_knowledge.js --task polls --query "..."
  node pipeline/scripts/query_knowledge.js --task mail --query "..."
  node pipeline/scripts/query_knowledge.js --task proofread --query "..."
  ```
- 拿不准的规则 → 回去查对应项目的 SOP.md / rules/ / GRADING_RULES.md，不要凭感觉。

---

## 四、遇到错误必须及时汇报

- 同一步骤连续失败 2 次 → **停止重试**，诊断根因后换思路。
- 登录/验证码/权限问题 → **立即通知用户**去 noVNC（`http://127.0.0.1:6082/vnc.html`）。
- 不要硬试、不要反复打补丁。
- **严禁**静默失败或假装成功。

---

## 五、提交前必须复检

- [ ] 所有维度的选项都已填写
- [ ] 验证脚本已确认无遗漏
- [ ] 计时器已满足最低要求
- [ ] Submit 后确认成功
- [ ] 正确进入下一题
