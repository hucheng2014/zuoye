Objective:
•Understand error trends across dimensions
•Identify root causes driving annotation mistakes
•Define action plan for calibration and quality improvement

Error Breakdown
Completeness and Correctness are the main contributors to the error trend issues, followed by pairwise
comparison, which is a result of mistakes being made in the individual dimensions. For Chinese, Korean,
Japanese and Vietnamese, Edit Necessity (equivalent to Correctness) and actual Errors found and corrected
(equivalent to Completeness) have the highest amount of issues found.
1. Completeness
Many graders seem to miss mistakes that weren’t caught by the model, rating responses one level above
where they should be rated (ie complete instead of nearly complete, or nearly complete instead of partial).
2. Edit Necessity & Correctness
There is a lot of inconsistency when annotating correctness. This applies to both incorrectly up-grading
(marking all when only some are necessary, or mixed when none are) and down-grading (marking none
when some are necessary, or mixed when all of them are).
3. Pairwise Comparison
Similar issue as in correctness, there is a lot of inconsistency. There are many cases of ranking two
responses equally when one is slightly better, but also cases of ranking one response better than another
even though they are of equal quality.
4. Q1 text grammatically correct
A minor issue in terms of frequency, but there are cases where graders marked the text as containing no
errors when some errors are present.
5. Q2 Assistant make changes to the input
Occasionally, some annotators mark input and response as being different despite being identical.
6. Formality
In Korean and Japanese locales, there are a few instances of a formal text being marked as informal.

Root Cause Analysis
•Very inconsistent understanding of graded/tiered answers. Graders have issues adjudicating what
“level” to evaluate the response for completeness, correctness, and pairwise comparison.
•Graders easily overlook changes in the response when they are minor, such as changes in spacing,
punctuation, or capitalization.
•Lack of understanding of the distinction between formal/semi-formal and informal leads graders to
often over-penalize edit necessity in informal texts.
Action Plan
•Completeness: read input text attentively before checking the responses. Don’t assume the
response has caught all mistakes.
•Correctness: make sure whether the edits in the response match their formality level.
•Pairwise comparison: compare the two responses closely; make sure you take the grading for the
completeness and correctness dimensions into account.
•Q1 text grammatically correct: read the input text closely and take into account the formality level.
•Q2 assistant make changes to input: pay special attention to things like changes in spacing and
punctuation, as these are easily overlooked.
Severity Calibration
Completeness
•Complete: the response edits all errors (that require changing, in accordance to formality and
minimal edit principle).
•Nearly complete: misses less than 20% of errors (misses 1 error out of every 6/7/8+ present).
•Partial: misses 20% or more of errors (misses 1 error out of every 3/4/5).
•Incomplete: misses most or all errors (misses half the errors or more).
Correctness
•Yes, all edits are necessary: all of the edits in the response are necessary according to formality
level and minimal edit principle.
•Mixed: some of the edits are unnecessary (even if it’s just one).
•No, all edits are unnecessary: none of the edits are necessary.
Calibration note: formality can determine whether an edit is necessary or not. In informal inputs, errors in
punctuation, capitalization, and spacing are acceptable.
Pairwise comparison
•About the same: the grading for both dimensions is the same for each response. The responses
don’t need to be identical!
•Slightly better: the grading for both dimensions is close; one response has a slightly better grade in
one of the dimensions.
•Much better: the grading for one response is much better than the grading of the other.
Calibration note: use the final grading as a guide for comparison. Two responses that are different will often
still be equally acceptable if they’re of the same quality.

Q1 text grammatically correct
•No errors: the text contains no errors, according to its formality level.
•Yes, the input contains errors: the text contains one or more errors, according to its formality level.
Calibration note: as noted in correctness, pay close attention to whether the text is informal or not.
Informal texts don’t require changes to punctuation, capitalization, etc. if they don’t alter the meaning.
Q2 assistant make changes to input
•Yes, the response is different: the response made changes to the input, including spacing,
capitalization, and punctuation.
•No, the response is identical: the response made no changes whatsoever to the input.
