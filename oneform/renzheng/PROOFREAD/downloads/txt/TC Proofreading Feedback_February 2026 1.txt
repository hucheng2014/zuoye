TC Proofreading Feedback – February 2026
Instructions Following
• Avoid rating responses as "Fully Following" when errors are still present or when unnecessary
changes were made to the original text.
• "Partially Following" applies only when the original intent is preserved and deviations are minor
(e.g., wording, tone, style). If the intent itself is altered, the correct rating is "Not Following.”
• If even one out of a few error was not fixed - Partially Following.
• If the response is an exact match, it’s Fully Following irrelevant if it has errors or not.
• Be mindful of both under- and over-penalization - when in doubt, revisit the guideline
thresholds.
Composition
• Do not rate a response as "Good" if errors remain uncorrected or if new errors were introduced.
• Reserve "Bad" for responses where almost no corrections were made, new errors were
introduced, or tone/style was significantly changed.
• Use "Acceptable" when some errors remain but the response is largely correct.
• If wording or sentence structure was slightly changed, mark it as Acceptable.
Localization
• Only flag genuine localization issues - do not penalize responses for Composition-related
problems under this dimension.
• Be aware of known locale-specific patterns (e.g., comma after greeting for Danish, full-width
punctuation for Chinese, correct quotation marks to use).
• Remember, in this task, localization issues for spelling, grammar, punctuation/format are only
Localization errors if they’re wrong in your locale but correct in another locale!
Groundedness
• Any response that changes information intent from the original input, even subtly, should not be
rated "Fully Grounded". Any time you notice a word was changed or modified, verify whether it
alters the original meaning.
• Look carefully for wording changes that shift meaning and apply "Partially Grounded" where
appropriate.
• If the main intent of the input is contradicted, hallucinated or made up in the response, fail
Groundedness.
Satisfaction
• Satisfaction errors cascade from the issues in the previous dimensions.
• Satisfaction must reflect the overall quality across all dimensions. If issues exist in Instructions
Following or Composition, the Satisfaction score should be adjusted downward accordingly.
Refer to the Satisfaction criteria table in the guidelines.
• A response with notable issues in other dimensions can never be rated "Highly Satisfying".

Please refer to the examples below for reference.
