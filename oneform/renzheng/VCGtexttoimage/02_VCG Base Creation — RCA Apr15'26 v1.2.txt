Error Analysis
High concentration of errors in these dimensions:
    • Structural Integrity → Very High (all locales)
    • Contains All Requests → High
    • Style Match → High
    • Text Included or Requested → High
    • Captured by Camera → Medium-High
    • Visual Quality → Medium


Error Breakdown
Under-penalization is the dominant issue
Consistent across all locales and most dimensions:
    • Structural distortions (extra fingers, deformed limbs) marked minor instead of severe
    • Missing prompt elements graded as 'captures most' rather than 'not aligned'
    • Text errors (spelling, artifacts) identified but not reflected in the final score
    • Style mismatches acknowledged but scored too leniently
Trend: Annotators default to conservative grading rather than strict penalization

Guideline misunderstanding is frequent
   • Severity thresholds (minor / noticeable / severe) applied inconsistently across locales
   • Style categories (Genmoji, Illustration) confused with photorealism or generic AI
       aesthetics
   • Photorealism judged by personal impression rather than objective visual cues
   • Flag criteria for trademarked content overlooked
   • 2b Text tag marked when no text was requested (N/A should apply)
Trend: Guideline understanding and calibration gap

Inconsistency (over- and under-penalization)
    • Structural Integrity: Severely flawed images passed; clean images penalized
    • Visual Quality: Blurry subjects missed; clear images downgraded
    • Captured by Camera: AI-generated images pass as realistic; genuine photos downgraded
    • Flag: Neutral content flagged without justification
Trend: No stable shared calibration — assessments vary by individual
Prompt reading is incomplete
   • Specific quantities and attributes missed during review
   • Partial fulfillment accepted without checking all prompt constraints
   • Text requirements not verified against output
Trend: Visual impression prioritized over systematic prompt verification

Style recognition is shallow
    • Style names recognized but not visually validated
    • Mixed/hybrid styles not consistently penalized
    • Illustration accepted as Genmoji; photorealism confused with style match
Trend: Style evaluation requires calibration that has not been sufficiently instructed

A/B and Preference Ranking errors
   • Better-looking image selected instead of the one with fewer prompt failures
   • PR rankings contradict dimension-level assessments within the same task
Trend: Limited ability to evaluate comparatively, not just assess in absolute terms.

   •   Style understanding is low — style names recognized but not visually validated
   •   Prompts read partially — constraints around objects, actions, text, and style are missed
