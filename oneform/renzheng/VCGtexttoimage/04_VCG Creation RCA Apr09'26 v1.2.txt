Error Analysis
   •   High concentration of errors in the following areas:
          a. Structural Integrity → High (5+)
          b. Style Match → High (5+)
          c. Contains All Requests → High (4–5)
          d. Text-related errors → Also significant (5)

Grader team is struggling most with:
   • Understanding what the image should look like structurally
   • Interpreting style incorrectly (Genmoji, Chibi, etc.)
   • Fully checking prompt completeness

Error Breakup
   •   Under-penalization is the dominant issue
          o Across multiple entries:
                ▪ Minor issues marked when they should be major
                ▪ Missing elements not penalized enough
                ▪ Structural issues downplayed
          o Example patterns:
                ▪ Extra fingers / distorted limbs → marked “minor”
                ▪ Missing key prompt elements → still marked “captures most”
          o Trend: Team is being lenient / conservative in grading

   •   Guideline misunderstanding is frequent
          o Repeated root causes:
                 ▪ “GL Misunderstanding”
                 ▪ “Misread Context”
                 ▪ “Missed Key Information”
          o Especially in:
                 ▪ Style Match
                 ▪ Text inclusion
                 ▪ A/B comparisons
          o Trend: Not a skill issue — it’s a guideline clarity + interpretation issue

   •   Text handling is messy
          o Common issues:
                 ▪ Missing text not caught
                 ▪ Text present but wrongly judged
                 ▪ Spelling/case errors ignored or misgraded
           o Example:
                ▪ “SIILENCE” not penalized correctly
                ▪ Text required but marked as not needed
           o Trend: No consistent framework for evaluating text

   •   A/B judgment errors (Comparison mistakes)
          o “A slightly better vs B perfect” misjudged
          o Context ignored while comparing
          o Wrong winner selected despite clear flaws
          o Trend: Weak relative evaluation skills, not just absolute grading

RCA

       (under-penalize)
   • Graders are: Observing randomly instead of following a structured scan
   • Style understanding is shallow: Graders recognize style names but don't visually
       validate them
   • Read prompts partially and miss constraints (objects, actions, text, style)
