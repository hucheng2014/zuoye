Task Overview

The goal of this group of projects is to evaluate the quality of machine-generated products in relevance to an input request or prompt. The
products can include texts, sketches, emojis, and more. Therefore, it is important to review the guidelines specific to the project you are working
on to ensure your understanding of the task entirely. Please see the Image Evaluation Guidelines below to review the foundation of these
projects.

In this task, you will be shown:
 • an input prompt
 • output image(s)
 • reference emojis
     • these are Apple s existing emojis relevant to a character or an object mentioned in the input prompt, such as a pink heart, tears of joy, or
        folded hands.
     • note: some prompts may not have any reference emojis.
Your job is to evaluate the quality of the emojis in relevance to the given input prompt using the Image Evaluation Guidelines in combination with
the project-specific guidelines listed on this page.

Ranking Scale
Compare and rank each Output Image based on the grades you assigned for the following dimensions found on the Image Evaluation Guidelines.

- Structural Integrity
- Input/Output Alignment
 • Text to Image Alignment
 • Image to Image Alignment
Leave a Comment


Provide a concise, specific, well-structured comment that explains your decision-making process to the engineers.
Special Note on Background Segmentation
In certain evaluation projects, the goal is to assess how effectively the object or people are separated from the background scene. In such cases,
you will see the emoji displayed on a solid green background in the grading UI (see examples below). This background is provided to help you
identify any artifacts or areas that have been improperly carved out.

• The solid green background can be treated the same as a white background. When grading the "input-output" alignment question, you
   should consider if any of the element mentioned in the prompt (e.g., beach, forest, city) is missing from the output emoji.
