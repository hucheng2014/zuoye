Error Breakdown
Under-penalization is the dominant issue
The most frequent root cause across the report. Annotators consistently graded issues less harshly than
guidelines require:
• Structural distortions (deformed faces, floating objects, impossible animal positions) rated
‘Mostly accurate’ or ‘Somewhat accurate’ instead of ‘Not accurate’
• Difficult-to-read text on edited objects accepted without penalization under Structural Integrity
• Annotators appear to default to lenient ratings rather than applying objective severity
thresholds
Trend: Conservative grading — annotators avoid applying strict penalties
Missed Key Information
Annotators overlooked specific prompt requirements during evaluation:
• Partial instruction fulfillment accepted: cactus arms unchanged, fish expression/direction
ignored, background not fully transformed
• Specific visual details (salmon skin color, animation level of croissant) not verified against
prompt
• Evaluators appear to rely on general visual impression rather than systematic prompt
verification
Trend: Prompt coverage is checked incompletely — overall impression overrides detail-level verification

Guideline Misunderstanding
Several errors reflect incorrect application of the guidelines themselves:
• Unedited Portion Consistency: annotators penalized images where the unedited portion was
fully preserved (‘Highly consistent’ downgraded)
• Missing eggs attributed to consistency dimension rather than edit instruction fulfillment
• Style evaluation: Genmoji confused with photorealism; animation level not assessed against
style spec
Trend: Calibration gap — guidelines not consistently internalized across annotators
Over-penalization (minority but notable)
A smaller but meaningful cluster of errors where annotators were too strict:
• Darkness of an image graded as a quality issue, when darkness was explicitly requested in the
prompt
• Visually clean images with good lighting and color downgraded under Integration and Visual
Quality
• Unedited portions with zero changes penalized instead of rated ‘Highly consistent’
Trend: Prompt context not consulted before penalizing — evaluations made in isolation from
instructions
Root Cause Analysis
• Severity thresholds are not calibrated — annotators default to mid-range ratings and avoid ‘Not
accurate’ or ‘Not aligned’ even when clearly warranted
• Prompt reading is incomplete — specific attributes, quantities, and style requirements are not
systematically checked before grading
• Guideline scope confusion — dimensions like Unedited Portion Consistency and Style Alignment
are applied to scenarios they don’t govern
• Context-blind penalization — some penalties applied without checking whether the visual
characteristic was intentional per the prompt
• No shared calibration reference — grading varies by individual rather than by a consistent
standard
Action Plan
Structured Evaluation Order
Annotators should follow a fixed scan sequence before assigning any rating:
• Follow Edit Instructions — check EVERY requested change against the output
• Structural Integrity — anatomy, objects, spatial logic
• Style Alignment — validate visually, not just by style name recognition
• Unedited Portion Consistency — confirm areas not part of request are unchanged
• Integration and Visual Quality — assess blurriness, color, lighting; account for prompt intent
