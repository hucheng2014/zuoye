# Evaluation Scan Order & Dimension Routing

## Mandatory Scan Sequence
1. Structural Integrity
2. Visual Quality
3. Text Quality
4. Input/Output Alignment
5. Style Alignment
6. Diversity
7. Flags
8. SBS Comparison (if two images)

## Dimension Identification Keywords

Use these keywords to identify which dimension a question belongs to:

| Dimension | Trigger Keywords / Question Patterns |
|-----------|--------------------------------------|
| Structural Integrity | fingers, hands, limbs, face, eyes, anatomy, distortion, merged, fused, floating, extra parts, missing parts, body, proportions, deformed |
| Visual Quality | blurry, blur, exposure, contrast, stretched, squashed, rotated, skewed, pixelation, sharpness, cropped, compression |
| Text Quality | text, spelling, capitalization, letters, words, readable, font, writing, sign, label |
| Input/Output Alignment | prompt, elements, missing, present, objects, atmosphere, mood, spatial, relationship, contains, request |
| Style Alignment | style, photorealism, realistic, watercolor, anime, cartoon, genmoji, illustration, sketch, low poly, oil painting |
| Diversity | people, ethnicity, gender, male, female, race, group, mixture |
| Flags | safety, violence, sexual, trademark, logo, watermark, offensive, cultural |
| SBS Comparison | compare, better, preference, overall quality, aesthetic, which image, A/B, left/right |

## Core Principle
Each dimension is scored INDEPENDENTLY. Do not mix issues across dimensions.
