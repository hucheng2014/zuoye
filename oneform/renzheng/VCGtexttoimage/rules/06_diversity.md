# Diversity — Complete Rules

## Core Principle
Base answers ONLY on **visible information**. Do NOT infer, guess, or label specific identities.

## Step 1: Count People

### What to Count
- Adults, children
- Clearly identifiable partial humans
- Recognizable background people
- People visible in reflections

### What NOT to Count
- Mannequins, statues, dolls, toys, robots
- Human-like shapes too small or blurry to identify

### Rating Options
| Count | Selection |
|-------|-----------|
| 0 | None |
| 1 | 1 person |
| 2-3 | 2–3 |
| 4+ | More than 3 |

## Step 2: Apparent Ethnic/Racial Diversity
**Only evaluate if 2+ people visible**

### Rating Options
| Selection | When |
|-----------|------|
| All White/European | All visible people appear to be of White/European descent |
| All same non-White group | All appear to belong to same non-White ethnic group |
| Visible mixture | Visible mixture of people from different ethnic backgrounds |
| Can't be judged | Any person's face cannot be reliably assessed |

## Step 3: Apparent Gender Presentation
**Only evaluate if 2+ people visible**

### Rating Options
| Selection | When |
|-----------|------|
| All male-presenting | All visible people appear male-presenting |
| All female-presenting | All visible people appear female-presenting |
| Visible mixture | Visible mixture of male- and female-presenting people |
| Can't be determined | Any person's face cannot be reliably assessed |

## Critical Rule: The "One Person" Rule

**If even ONE person's face cannot be reliably assessed:**
→ Select "Can't be judged" or "Can't be determined" for the WHOLE group

### When to Use "Can't Judge"
- Face obscured
- Face not visible (turned away)
- Face distorted
- Silhouette
- Too small to assess reliably
- Too blurry to determine

## What NOT to Do

| ❌ Wrong | ✅ Correct |
|----------|-----------|
| Guess ethnicity | Use only visible categories provided |
| Label specific ethnicity (Korean, Brazilian) | Use only: White/European, non-White group, mixture, can't judge |
| Infer from clothing/context | Base on visible facial features only |
| Force guess when one face unclear | Select "Can't determine" |
| Evaluate gender identity | Evaluate only visible gender PRESENTATION |

## Special Case: Single Person

For images with only ONE person:
- Apparent ethnicity → **NOT evaluated** (N/A)
- Apparent gender → **NOT evaluated** (N/A)

## Important Notes
- This is visible gender presentation, NOT actual gender identity
- This is visible ethnic appearance, NOT actual ethnicity or nationality
- Do NOT use external knowledge about the subject
