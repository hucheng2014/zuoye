# SBS (Side-by-Side) Comparison — Complete Rules

## When to Use
After completing single-image dimension scoring for BOTH images.

## Two Questions

### Question 1: Overall Quality

**Basis:** Dimension-level scores already assigned
- Structural Integrity
- Visual Quality
- Style Alignment
- Input/Output Alignment
- Text Quality

**Core Principle:** Choose the image with **FEWER ERRORS**, NOT the prettier one.

**Decision Checklist:**
1. Which image misses fewer prompt elements?
2. Which image has fewer structural issues?
3. Which image has better visual quality?
4. Which image matches style better?
5. Which image has fewer text errors?
6. Are comparison scores consistent with dimension-level assessments?

**Weight Guidance:**
- If one image is MUCH stronger in a key dimension (e.g., Alignment), that may outweigh a small advantage in a less important dimension
- Do NOT restart evaluation based on personal taste
- Use the dimension scores already assigned

### Question 2: Aesthetic Quality

**Basis:** Visual appeal, separate from technical correctness

**Factors:**
- Composition
- Lighting
- Color
- Subject-background relationship
- Clarity
- Visual polish

**Note:** This is closer to first impression but considers visual craftsmanship.

## Rating Scale

| Rating | Meaning |
|--------|---------|
| **Better** | Clear, significant difference |
| **Slightly Better** | Moderate but meaningful difference |
| **Same / About the Same** | No meaningful difference, or both succeed/fail similarly |

## Critical Rules

| ❌ Wrong | ✅ Correct |
|----------|-----------|
| Prettier image wins | Image with FEWER ERRORS wins (Overall Quality) |
| Ignore dimension scores | Use dimension scores as basis |
| Aesthetic = Overall | Aesthetic is separate from technical correctness |
| Personal preference decides | Follow structured comparison checklist |

## Common Mistakes

1. **Choosing prettier image over less-error image**
   - Example: Image A has structural defects but nice colors; Image B has minor alignment issue but structurally sound
   - Wrong: Choose A because it looks better
   - Correct: Choose B because it has fewer critical errors

2. **Ignoring dimension scores**
   - Dimension scores MUST inform Overall Quality choice
   - Cannot contradict dimension-level assessments

3. **Inconsistent Preference Ranking**
   - PR rankings must be consistent with dimension-level assessments
   - If Image A scores better on most dimensions, it should win Overall Quality

## Evaluation Order
1. Complete single-image dimension scoring for Left image
2. Complete single-image dimension scoring for Right image
3. Compare Overall Quality (based on dimension scores)
4. Compare Aesthetic Quality (based on visual appeal)
