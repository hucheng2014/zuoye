Preference Ranking Guidelines - Info The Preference Ranking Guidelines have been updated to v5, so please ﬁnd below some information on the most important updates: The main update is related to the Localization question.  - The criteria for what is considered a localization issue has now been broadened, more speciﬁcally for the following categories: Grammar, Spelling, Formatting and Punctuation, and Tone. These categories’ deﬁnitions now include all kinds of Grammar, Spelling, Formatting and Punctuation and Tone issues, not just issues which are incorrect in your locale but possibly correct in another (ex. Incorrect in fr-fr, but correct in fr-ca) - Many examples have been added for several languages, so please check them out at the end of the Guidelines so as to better understand these new deﬁnitions for the diMerent types of localization issues NOTE: In the tasks themselves, you will see this ‘v5’ of the Guidelines being mentioned, so when you notice this please make sure you’re applying the criteria from these updated v5 Guidelines. If you notice that ‘v3’ is referenced, then please use the previous Guidelines’ version accordingly.  (*We know you cannot access the links themselves that appear for any Guidelines’ version in the tool, so no concerns there, just focus on the version number speciﬁed)
