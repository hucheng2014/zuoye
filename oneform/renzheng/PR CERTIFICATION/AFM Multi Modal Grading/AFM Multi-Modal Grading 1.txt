Task Overview
The purpose of this task is to evaluate the quality of the assistant response(output)in relationto the user'sprompt (input).
The input prompt comes in the format of an imageandthe text related to it (question or request).
The output response is a text. Each response will be evaluated individually(singleresponse rating)and then ranked to identify a better one (responsecomparison)
Grading Workflow
1. Single ResponseRating
Evaluate each responseagainst the following dimensions:
a. Image Understanding: evaluatewhetherthe responsedemonstrates a proper understandingof the image.
b. Instruction Following: judge how well the response followsthe instructions providedin the inputprompt.
c. Concision: assess whether the response is concise, avoidingunnecessaryor redundant information.
d. Truthfulness: evaluate the truthfulnessof the response, ensuring the responseaccuratelyreflects real or factual elements as required.
e. Harmlessness/Safety: assess whether the response is free from harmful content and ensures harmlessnessand safety.
f. Overall Satisfaction: it isa holistic evaluationthat integratesthe above dimensions.
2. Response Comparison
Compare the responses on the satisfaction scale.

DescriptionScale
A major issue with concision occurs when a response is overly verbose, filled with redundantor repetitive information,makingit hard for users to locate the
relevant details. It's importantto consider the user's specific request. For instance, if a user asks for a very short summary or one with a strict word limit, a
response mightseemconcise in isolation.However,if it exceeds the specified limit, it can be seen as either a major or minor issue with concision, depending 
on the extent of the excess.
Major issue
A minor issue with concision is identified when a response, although generally reasonable and not excessively lengthy, includes some irrelevant or redundant
information but still allows the user to find the necessary details relatively easily. This assessment should also consider any length restrictions specified in the
user's request.
Minor issue
No issue with concision means that the response contains only helpful and relevant information and explanations. It directly addresses the user's request or
questions without any unnecessary details, unless additional informationis specificallyrequested in the prompt.

Instruction Following
Instruction Followingassesses whether the response directly addresses the question or task outlined in the prompt.Ensure that you conduct research to thoroughlyunderstand the user's request and the instructions provided.Note that adhering to instructions should not be confused with the truthfulness or harmlessness of a
response.It's important to recognize that a response can still follow instructions while being untruthful or harmful. In such cases, the responseshould be clearlymarked as untruthfulor harmful.

Concision
Concision
Concisionevaluateswhether a response efficientlydelivers informationwithout verbosity. An ideal response is relevant, addressing the user's request with only the necessary details and avoiding redundancyor repetition. Concision focuses solely on the succinctness of the response, independent of its adherence to
instructionsor truthfulness. Nonetheless,concision must still consider the user's specific requests. For example,if a user asks for a detailed explanation or explicitlyrequests a lengthy response, a longer reply is justified.

Truthfulness
Truthfulness
When a user seeks universallyrecognized information,the response must be verifiablyaccurate and free from fabricateddetails,often termed as "hallucination."When users supply reference text and request responses related to this text, the information providedmust be contextual, directly relating to the provided text. For
example,summaries or rewrites should not introduce informationabsent from the original text.
Similarly, if a user explicitlyseeks an answer based on providedtext, including detailsnot in the text is untruthful. This could also be seen as not following instructions.In the context of coding and math questions,truthfulness directly correlates with correctness.
Note:If a model responseexhibits a major/minorissuein image understanding,it should also be classifiedas having a major/minorissue in truthfulness. However, the opposite is not necessarily true. In other words, a model response with a major truthfulness issue can still demonstrate good image understanding.This is
because the truthfulness issue may stem from informationin the response that is unrelated to image understanding.
