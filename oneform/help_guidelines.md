### Help

#### How to annotate

- The task might support adding time intervals (annotations with a start and end timestamp), time points (annotations with a single timestamp), or both.
- Time intervals can be added by clicking (or pressing the shortcut `a`) twice to mark the start and end of the time interval in the `Charts View`.
- Time points can be added by clicking or pressing `a` once on the `Charts View`.
- After an annotation is added, questions usually have to be answered over the `Questions Panel` before adding new annotations.
- A task might additionally require answering general questions before any annotation can be added.
- A list of the annotations added is shown in the  `Annotations Panel`.
- Annotations may be modified (dragging them with the mouse, resizing time intervals) or deleted with `delete`.
- Time intervals may overlap each other. To add an annotation inside a time interval, hold `alt` while adding the annotation with the mouse click or with the shortcut `a`.

#### Questions Panel

- Questions might be required or optional. Required questions must be answered before other annotations can be added, selected or modified and before the task can be submitted.
- Questions might require selecting one of many options (i.e. radio), selecting all options that apply (i.e. checkbox) and typing free text.
- Questions might have nested questions that are only visible after specific answers have been provided.

#### Mouse

|    Button     | Description                        |
| :-----------: | :--------------------------------- |
| `left-click`  | add, select and modify annotations |
| `right-click` | pan chart  or video                        |
|  `wheel`  | zoom in and out of chart or video           |


#### Hotkeys

|     Key     | Description                                                                       |
| :---------: | :-------------------------------------------------------------------------------- |
| `spacebar`  | toggle play and pause.                                                            |
|   `shift`   | hold shift while moving the mouse to move the playhead                            |
|     `q`     | lower media playback speed rate                                                   |
|     `w`     | increase media playback speed rate                                                |
|     `r`     | reset chart zoom and offset                                                       |
|     `a`     | annotate chart at current mouse position (same as left-click)                     |
|     `s`     | zoom out |
|     `d`     | zoom out |
|     `h`     | shows / hides annotation labels |
|     `e`     | toggle annotation mode (only when time interval and time point tools are enabled) |
|     `v`     | toggles automatic vertical scaling while held down |
|    `esc`    | deselect annotation. If annotations have been suggested (annotations with dashed lines), it deletes them.                                                               |
|  `delete`   | delete selected annotation                                                        |
| `backspace` | delete selected annotation                                                        |
|  `cmd + delete`   | delete all annotations                                                        |
|    `alt + click`    | enables annotations on top of an time interval annotation.                        |
|    `alt + right`    | moves playhead to the end.                        |
|    `alt + left`    | moves playhead to the start.                        |
|    `right`    | moves playhead to the right. Hold shift to double the distance the playhead moves.                       |
|    `left`    | moves playhead to the left. Hold shift to double the distance the playhead moves.                        |
|    `up`    | selects the previous annotation in the annotations panel.                        |
|    `down`    | selects the next annotation in the annotations panel.                        |
|    `l`    | scroll chart right.                        |
|    `k`    | scroll chart left.                        |
