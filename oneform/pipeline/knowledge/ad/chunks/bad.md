# Bad Rating -- Detailed Criteria

## Definition
The advertised app has **no meaningful relation** to the search query. A user would be **surprised** to see this ad in their search results. There is no logical reason for this app to appear.

**MANDATORY: All Bad ratings MUST include an explanatory comment.**

## Core Scenarios

### 1. No Logical Link
There is simply no connection between the query and the advertised app.

- Query: "weather app" -> App: "Dating app" = **Bad** (no connection)
- Query: "Spotify" -> App: "Banking app" = **Bad** (music has no relation to banking)
- Query: "photo editor" -> App: "Food delivery app" = **Bad** (no connection)
- Query: "fitness tracker" -> App: "News reader" = **Bad** (no connection)

### 2. Surface Word Overlap but Different Context (COMMON PITFALL)
The app name or description shares words with the query, but the meaning is entirely different. This is the most dangerous trap -- do not be fooled by keyword matches.

- Query: "Apple" (the tech company) -> App: "Apple recipes cooking" = **Bad** (same word, completely different meaning)
- Query: "Jaguar" (the car brand) -> App: "Jaguar wildlife tracker" = **Bad** (same word, different domain)
- Query: "Crane" (construction equipment) -> App: "Origami crane tutorial" = **Bad** (same word, different context)
- Query: "Mercury" (car or planet) -> App: "Mercury retrograde astrology" = **Bad** if user clearly meant the car brand
- Query: "Coach" (the luxury brand) -> App: "Life coach app" = **Bad** (same word, different meaning)

### 3. Different Domain, Audience, and Purpose
Even if some very distant thematic thread exists, the app is fundamentally for a different audience with different needs.

- Query: "kids coloring book" -> App: "Professional graphic design suite" = **Bad** (both involve drawing/art but completely different audiences and purposes)
- Query: "baby monitor" -> App: "Home security camera" = **Bad** if the security camera has no baby monitoring features (superficially similar hardware concept, different purpose)
- Query: "pet care" -> App: "Veterinary school textbook" = **Bad** (pet-related but for professional students, not pet owners)

### 4. Context Mismatch After Research
After researching the query's context (locale, abbreviation meaning, brand), the app has no relation to the actual intent.

- Query: "12315" (Chinese consumer complaint hotline) -> App: "Random number game" = **Bad** (surface number match, no functional relation)
- Query: "BBC" (in UK context: British Broadcasting Corporation) -> App: "BBC pump company" = **Bad** (acronym overlap, different entity)

## Comment Requirement

Every Bad rating MUST include a comment explaining:
1. What the user was searching for (query intent)
2. What the advertised app does (app function)
3. Why there is no meaningful relationship
4. Confirmation that the rating is Bad

Example comment:
> The user searched for "Spotify," a music streaming service. The advertised app is a banking/finance application. There is no meaningful relationship between music streaming and financial services. Rating: Bad.

## Key Principle
Ask: "Would the user be confused or annoyed to see this ad?" If yes, rate Bad -- and explain why in a comment.
