# Good Rating -- Detailed Criteria

## Definition
The advertised app has **some relation** to the search query. A user searching for this query would be **quite likely** interested in this app, but other results would be **more compelling**.

## Core Scenarios

### 1. Close but Not Exact Functionality
The app does something related but not identical to what the query asks for.

- Query: "photo editor" -> App: "Canva - Design & Photo" = **Good** (Canva has photo editing but is primarily a design tool)
- Query: "video player" -> App: "VLC media player" = **Good** if the app is primarily an all-format media player rather than a dedicated video experience
- Query: "running tracker" -> App: "MyFitnessPal" = **Good** (fitness related but primarily calorie/diet tracking)
- Query: "note taking app" -> App: "Todoist" = **Good** (productivity adjacent but task management, not notes)

### 2. Accessory or Add-On
The app is a companion, extension, or accessory to the searched app.

- Query: "Minecraft" -> App: "Minecraft Skins Creator" = **Good** (add-on/companion for Minecraft)
- Query: "Instagram" -> App: "InShot - Video Editor" = **Good** (commonly used to create content for Instagram)
- Query: "GarageBand" -> App: "Music Tuner" = **Good** (accessory tool for musicians using GarageBand)
- Query: "Zoom" -> App: "Zoom Whiteboard" = **Good** if it is a separate companion app

### 3. Same Ecosystem, Narrower or Wider Scope
The app operates in the same domain but at a different scope level.

- Query: "travel planner" -> App: "Airbnb" = **Good** (travel ecosystem but narrowly focused on accommodation)
- Query: "food delivery" -> App: "Yelp" = **Good** (food ecosystem but focused on reviews, not delivery)
- Query: "photo editor" -> App: "VSCO" = **Good** (photo ecosystem but primarily filters/presets, narrower editing scope)
- Query: "fitness app" -> App: "Strava" = **Good** (fitness but specifically cycling/running tracking)

### 4. Related Category, Different Primary Use
The app shares the broad category but has a different primary purpose that still interests the same user.

- Query: "Spotify" -> App: "SoundCloud" = **Good** (both music streaming but SoundCloud focuses on independent/uploaded music)
- Query: "Google Docs" -> App: "Notion" = **Good** (both productivity but Notion is a broader workspace tool)
- Query: "Duolingo" -> App: "Babbel" = **Good** (both language learning but different methodology; could also be Excellent as a direct competitor depending on market positioning)

## Game-Specific Good

- Query: "Candy Crush" -> App: "Bejeweled" = **Good** (similar match-3 mechanic but different IP, less direct competitor)
- Query: "racing game" -> App: "CSR Racing" = **Good** if user searched broadly and this is one of several racing games but not the most prominent
- Query: "Minecraft" -> App: "Terraria" = **Good** (similar sandbox/survival genre but 2D vs 3D, different style)

## Key Principle
Ask: "Would this app interest the user, but would they wish they found something closer to their query?" If yes, rate Good.
