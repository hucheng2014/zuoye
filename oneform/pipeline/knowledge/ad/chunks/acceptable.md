# Acceptable Rating -- Detailed Criteria

## Definition
The advertised app has a **slight relation** to the search query. A user would **not be surprised** to see this ad but would **not likely be interested** in clicking on it.

## Core Scenarios

### 1. Same Broad Category, Different Specific Needs
The app and query share a general category but target different sub-needs within that category.

- Query: "photo editor" -> App: "Google Photos" = **Acceptable** (both deal with photos, but Google Photos is storage/organization, not editing)
- Query: "cooking recipes" -> App: "Grocery delivery app" = **Acceptable** (both food-related but different needs)
- Query: "workout timer" -> App: "Sleep Cycle" = **Acceptable** (both health-related but very different functions)
- Query: "email client" -> App: "Slack" = **Acceptable** (both communication tools but different paradigms)

### 2. Same Developer, Different Theme/Purpose
The advertised app is from the same developer as the searched app but serves a substantially different purpose.

- Query: "Google Maps" -> App: "Google Translate" = **Acceptable** (same developer, but translation != navigation; travel overlap is thin)
- Query: "Adobe Photoshop" -> App: "Adobe Acrobat" = **Acceptable** (same developer, but PDF management != photo editing)
- Query: "Epic Games (Fortnite)" -> App: "Epic Games Store" = **Acceptable** (same developer, storefront vs game)

### 3. App Not Available in User's Locale
The app matches the query well but is not available in the user's App Store region. Regardless of how good the match is, unavailability caps the rating.

- Query: "BBC iPlayer" -> App: "BBC iPlayer" (unavailable outside UK) = **Acceptable**
- Query: "Hulu" -> App: "Hulu" (unavailable outside US/Japan) = **Acceptable**
- Any otherwise-Excellent app that the user cannot actually download = **Acceptable**

### 4. Tangential Relationship
A logical but weak connection exists. The user can see why this ad appeared but would not act on it.

- Query: "guitar tuner" -> App: "Piano app" = **Acceptable** (both music instruments but different instruments)
- Query: "flight tracker" -> App: "Hotel booking app" = **Acceptable** (both travel but different functions)
- Query: "calculator" -> App: "Unit converter" = **Acceptable** (both utility/math but different tools)
- Query: "calendar app" -> App: "Reminder app" = **Acceptable** (both time management, different approach)

## Game-Specific Acceptable

- Query: "Candy Crush" -> App: "Angry Birds" = **Acceptable** (both casual mobile games but completely different mechanics: match-3 vs physics puzzle)
- Query: "Call of Duty" -> App: "Chess app" = **Acceptable** (both games but entirely different genres, audiences, and play styles)
- Query: "racing game" -> App: "Flight simulator" = **Acceptable** (both vehicle-based but different categories)

## Key Principle
Ask: "Would the user understand why this ad appeared, but scroll past it?" If yes, rate Acceptable.
