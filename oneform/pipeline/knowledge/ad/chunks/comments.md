# Comment Requirements

## When Comments Are Required

| Rating    | Comment Required? |
|-----------|------------------|
| Excellent | Recommended      |
| Good      | Recommended      |
| Acceptable| Recommended      |
| Bad       | **MANDATORY**    |

All Bad ratings MUST have an explanatory comment. Submitting a Bad rating without a comment is a task error.

## Comment Structure Template

Follow this four-part structure for clear, consistent comments:

```
1. Query Intent:    What the user was searching for
2. App Function:    What the advertised app does
3. Relationship:    How (or whether) the two are connected
4. Rating:          The rating and why it fits
```

### Example: Excellent
> The user searched for "photo editor." The advertised app, Snapseed, is a full-featured photo editing application by Google. The app directly matches the user's search intent with comprehensive editing tools. Rating: Excellent.

### Example: Good
> The user searched for "Minecraft." The advertised app, Terraria, is a sandbox survival game with crafting and exploration mechanics similar to Minecraft but in 2D. While related in genre and appeal, it is not Minecraft itself or a direct competitor. Rating: Good.

### Example: Acceptable
> The user searched for "Google Maps." The advertised app, Google Translate, is a language translation tool by the same developer (Google). While both are useful for travelers, their core functions (navigation vs translation) differ significantly. Same developer provides a baseline connection. Rating: Acceptable.

### Example: Bad (MANDATORY)
> The user searched for "Spotify," a music streaming service. The advertised app is a personal finance/banking application. There is no meaningful relationship between music streaming and financial services -- different category, audience, and purpose. Rating: Bad.

## Rules for Writing Comments

### Never Mix Query/App Across Items
Each task has 5 items. Each item has its own query-app pair. When writing comments:
- Only reference the query and app for THAT specific item
- Do not copy a comment from item 1 and paste it into item 3
- Do not reference apps or queries from other items
- Each comment must be independently accurate

### Keep Comments Factual and Concise
- State facts, not opinions
- Describe what the app does, not whether it is good
- 2-4 sentences is sufficient
- Do not include app ratings, review counts, or price information

### Avoid These Errors
- Empty comments on Bad ratings (task error)
- Comments that contradict the selected rating
- Generic comments like "not relevant" without explanation
- Comments that describe the wrong app or wrong query
- Copy-pasted identical comments across all items

## Pre-Submission Comment Checklist

Before submitting the task, verify:
- [ ] Every Bad rating has a comment
- [ ] Each comment references the correct query and app for that item
- [ ] Comments are consistent with the selected ratings
- [ ] No comments are copied from a different item without adjustment
- [ ] Comments follow the 4-part structure (intent, function, relationship, rating)
