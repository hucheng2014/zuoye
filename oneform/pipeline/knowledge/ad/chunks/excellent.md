# Excellent Rating -- Detailed Criteria

## Definition
The advertised app has a **strong relationship** to the search query. A user searching for this query would **most likely** be interested in this app.

## Core Scenarios

### 1. Exact or Near-Exact Name Match
The app name matches the query text exactly or with trivial variation.

- Query: "WhatsApp" -> App: "WhatsApp Messenger" = **Excellent**
- Query: "Instagram" -> App: "Instagram" = **Excellent**
- Query: "Spotify" -> App: "Spotify - Music and Podcasts" = **Excellent**

### 2. Developer Match + Same Category
The advertised app is made by the same developer as the searched app and serves a related purpose.

- Query: "Google Maps" -> App: "Google Earth" = **Excellent** (same developer, same domain: mapping/geography)
- Query: "Adobe Photoshop" -> App: "Adobe Lightroom" = **Excellent** (same developer, same domain: photo editing)
- Query: "Microsoft Word" -> App: "Microsoft Excel" = **Excellent** (same developer, same domain: productivity/office)

### 3. Direct Competitors
The advertised app directly competes with the searched app -- same core functionality, same target audience.

- Query: "Uber" -> App: "Lyft" = **Excellent** (direct ride-hailing competitors)
- Query: "Spotify" -> App: "Apple Music" = **Excellent** (direct music streaming competitors)
- Query: "Google Chrome" -> App: "Firefox" = **Excellent** (direct browser competitors)
- Query: "Zoom" -> App: "Microsoft Teams" = **Excellent** (direct video conferencing competitors)

### 4. Core Functionality Match
The query describes a function and the app delivers exactly that function.

- Query: "photo editor" -> App: "Snapseed" = **Excellent** (Snapseed is a photo editor)
- Query: "meditation app" -> App: "Headspace" = **Excellent** (Headspace is a meditation app)
- Query: "password manager" -> App: "1Password" = **Excellent** (1Password is a password manager)
- Query: "weather forecast" -> App: "Weather.com" = **Excellent**

## Game-Specific Excellent

- Query: "Candy Crush" -> App: "Candy Crush Saga" = **Excellent** (exact match)
- Query: "Candy Crush" -> App: "Candy Crush Soda Saga" = **Excellent** (same IP/franchise)
- Query: "PUBG" -> App: "PUBG Mobile" = **Excellent** (exact match, platform variant)
- Query: "battle royale game" -> App: "Fortnite" = **Excellent** (core genre match)
- Query: "Clash of Clans" -> App: "Clash Royale" = **Excellent** (same developer + IP universe)

## Key Principle
Ask: "If I searched for X, would I be delighted to see this app?" If the answer is a clear yes, rate Excellent.
