# Search Ads Relevance -- Operation Flow

## 8-Step Workflow

### Step 1: Read Query Text
- Identify the search query the user typed
- Understand user intent: what are they looking for?
- Note the locale/market context (language, country)

### Step 2: Review Advertised App Details
- Read the app name, developer, category, description
- Note the app's primary function and target audience
- Check if the app is available in the user's locale

### Step 3: Check App Store Search Results
- Review what appears in the App Store for this query
- Identify the top organic results for context
- Understand the competitive landscape for this query

### Step 4: Web Research (if needed)
- Research abbreviations, acronyms, or local terms you do not recognize
- Look up brand names, local service codes (e.g., "12315" in China)
- Verify developer relationships between apps
- Confirm locale-specific meanings (e.g., "BBC" varies by market)

### Step 5: Rate Each Item
- Evaluate all 5 advertised items independently
- Apply the 4-level relevance scale: Excellent / Good / Acceptable / Bad
- Consider query intent, app function, and the relationship between them
- Apply special rules: developer match, locale availability, competitor status

### Step 6: Write Comments
- Write comments for every item (mandatory for Bad, recommended for all)
- Follow structure: query intent -> app function -> relationship -> rating
- Never copy/paste comments between items without adjusting content
- Never mix query text or app details from different items

### Step 7: Pre-Submission Checklist
- [ ] All 5 items have a rating selected
- [ ] All items have comments (Bad ratings MUST have comments)
- [ ] Comments match the selected ratings (no contradictions)
- [ ] Bad ratings are explained with clear reasoning
- [ ] No query/app details mixed between different items
- [ ] Locale and context considerations documented where relevant

### Step 8: Submit
- Final review of the complete form
- Submit the task

## Iron Rules

- **No auto-scoring scripts** -- each item requires independent human/AI judgment
- **No auto-submission** -- always verify before submitting
- **No page refresh** during a task -- this can lose your work
- **No new tabs** for the task page -- use existing browser context
- **Research in order** -- query first, then app, then relationship
- **Document everything** -- comments serve as your reasoning trail
