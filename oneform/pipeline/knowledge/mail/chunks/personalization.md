# Personalization

## Purpose
Evaluate whether the draft reply reflects the sender's unique communication style as defined by their User Profile. Core factors: vocabulary level, paragraph formatting, sentence structure, greetings, sign-offs, and signatures.

## 4-Level Scale

### Personalized (Perfect Match)
The draft perfectly mirrors the sender's profile traits in format, vocabulary, tone, and structure. It reads as if the sender wrote it themselves.

Key checks:
- Sign-off matches profile (e.g. profile uses "Best regards" -> draft uses "Best regards")
- Signature/name matches profile convention
- Paragraph length and formatting consistent with profile
- Vocabulary level (formal/informal) matches profile

**Missing or wrong sign-off/signature when profile specifies one = significant downgrade.**

### Contextually Adapted (Context-Driven Style Shift)
The draft intentionally and reasonably deviates from the sender's usual profile style to fit the specific email context and social relationship. This is a POSITIVE adjustment, NOT a failure.

**CRITICAL: This is the most commonly misclassified level. Contextually Adapted is NOT a downgrade from Personalized.**

Case 1 -- Formatting adaptation:
- Profile: `lacks_formatting` (no paragraphs/line breaks)
- Context: business email to important client (e.g. Henriette)
- Draft: adds paragraphs and line breaks for business courtesy
- Verdict: **Contextually Adapted** (NOT Generic, NOT Mismatch)

Case 2 -- Tone adaptation:
- Profile: casual and friendly vocabulary
- Context: replying to a bereavement/serious event notification
- Draft: restrained and empathetic tone
- Verdict: **Contextually Adapted** (context demands different register)

### Generic (Template-Like)
The draft shows zero personality traits from the profile. It reads like a personality-less, formulaic standard business template with no human warmth or individualized touches.

Indicators:
- Cookie-cutter phrases with no personal voice
- Could have been written for any sender
- No profile-specific vocabulary, greeting, or sign-off

### Mismatch (Wrong Register)
The draft exhibits style elements that directly contradict the profile AND make no contextual sense. The mismatch cannot be explained by context adaptation.

Examples:
- Profile is extremely formal business writer, draft uses slang and emojis in a business context
- Profile always uses first-name basis, draft uses overly formal titles in a casual context

## Excessive Padding Warning
If the draft is stuffed with unnecessary filler phrases, boilerplate pleasantries, and redundant padding that inflates length far beyond the sender's typical brevity (as indicated by profile), this constitutes Excessive Padding and must be penalized.

Signs of excessive padding:
- Multiple sentences saying the same thing in different words
- Generic filler like "I hope this email finds you well" when profile is terse
- Unnecessary restatements of the prompt content
- Length 2-3x what the sender's profile would suggest

## Common Pitfalls
1. Seeing a formatting change from profile -> immediately calling it Generic or Mismatch (check if context justifies it first)
2. Ignoring sign-off/signature mismatch when profile clearly specifies one
3. Confusing Contextually Adapted with Generic (the key difference: Contextually Adapted shows intentional shifts for a reason; Generic shows no personality at all)
