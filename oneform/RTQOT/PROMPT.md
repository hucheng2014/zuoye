# AI Agent 自动化工作规范 — RTQOT 过渡质量评估

> **在开始做题前，请仔细阅读并严格遵守以下规则。这些是不可违反的硬性要求。**

---

## 项目简介

本项目在 TryRating 平台上评估**音频过渡质量**（transition quality），与 RQOAE 类似但评估维度不同。

---

## 一、每段音频必须独立分析，禁止硬编码

- 每段音频必须独立听和分析，不可用单一阈值批量判分。
- 不同过渡类型的评判标准可能不同。

---

## 二、必须使用现有脚本和流程

**核心脚本：**
- `solve_tasks.py` — 解题主脚本
- `skills/` 目录 — 评分技能文档

**必须阅读的规则文档：**
1. `transition_quality_rules.md` — **评分规则（最高优先级）**
2. 知识库：`pipeline/knowledge/rqoae/compact_sop.md`（参考）

---

## 三、严格按规则操作

- 按 `transition_quality_rules.md` 中的标准评分。
- 不确定的评分查阅规则文档，不凭感觉。

---

## 四、遇到错误必须及时汇报

- 音频下载失败 → **立即报告**。
- 同一错误重试 **≤2 次**，仍失败则停止。
- 登录/验证码/权限问题 → **立即通知用户**。
- **严禁**静默失败或假装成功。

---

## 五、提交前必须复检

- [ ] 每段音频已独立分析
- [ ] 评分基于规则文档，非单一阈值
- [ ] 页面评分已正确选中
- [ ] 提交后确认进入下一题

---

## 工作流程检查清单

```
[ ] 1. 我已读完 transition_quality_rules.md
[ ] 2. 我使用 solve_tasks.py 现有脚本
[ ] 3. 我的方案是每段音频独立分析
[ ] 4. 我知道遇到错误必须立即报告
[ ] 5. 我知道提交前必须复检
```
